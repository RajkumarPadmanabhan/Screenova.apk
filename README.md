# Screenova

Screenova is a private movie and series shelf for files already saved on your device. The page is hosted on GitHub Pages. The videos are not.

Open the site, choose the folder that holds your downloads, and Screenova builds a library from what is in that folder:

- Movies stay movies. A series with Season 1, Season 2, or filenames like `Show.S01E02` is grouped under one title.
- Each title shows its name, category, file size, and artwork.
- Rating and a short description are added when the title matches public details, or when you place `poster.jpg` and `movie.nfo` / `tvshow.nfo` beside the file.
- Chrome and Edge can remember the folder. The page reads it again when you open it, come back to the tab, or press refresh, so new downloads show up and removed files disappear.

Playback of MP4 and WebM stays in the browser. MKV and AVI still appear in the library with their size and details.

Nothing in the folder is uploaded to GitHub.
